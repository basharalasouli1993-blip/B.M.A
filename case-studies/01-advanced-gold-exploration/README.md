## Objective

Prioritize surface anomalies for staged field investigation using converging spectral, temporal, terrain and structural evidence.

## Documented workflow

| Stage | Analysis | Decision output |
| :--- | :--- | :--- |
| Preparation | Coverage review, clipping, alignment and common analytical grid | Comparable layers |
| Spectral screening | Enhancement, diagnostic ratios, PCA and Crosta | Possible alteration responses |
| Independent checks | Newer multi-date observations and response comparisons | Persistence and coincidence |
| Structural context | Hillshade, terrain metrics, lineament extraction and screening | Plausible structural associations |
| Integration | Review coherent overlapping responses and investigate background | Target A and sampling domains |
| Verification planning | Field reconnaissance, representative sampling and laboratory QA/QC | Staged investigation plan |

## Outputs and interpretation

The report identifies Target A as the first priority for follow-up and describes core, transition and peripheral reference domains. Confidence is stated separately for surface anomalies, possible alteration, mineral identity and gold presence.

The study contains no completed field verification, gold assay, drilling or resource estimate. The target boundary is an investigation boundary. The sampling and laboratory program is proposed work, not a completed deliverable.
