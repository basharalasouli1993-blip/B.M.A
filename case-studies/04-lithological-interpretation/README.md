## Oman: host-rock context

The existing Arabic report discusses chromite-associated exploration in ultramafic host rocks. It presents spectral composites, interpreted host-rock contrasts and comparisons of historical and recent imagery.

**Portfolio skills:** lithological context, comparative image interpretation, spectral-response communication and figure-led reporting.

The summary treats the imagery as surface evidence. It does not adopt colour-based statements about mineral concentration as measured grade.

## Mauritania: preliminary alteration screening

The existing 15-page Arabic report discusses spectral alteration indicators, composites and comparisons between imagery dates in an arid exploration setting.

**Portfolio skills:** spectral screening, potential alteration interpretation and technical explanation of multi-date imagery.

This is the preliminary report already present in the repository. It is not the newer integrated Mauritania report referenced in the prior conversation; that attachment was unavailable during this update. Advanced methods or results from the unavailable report are not attributed to this older study.
